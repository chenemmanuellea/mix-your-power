# Mix Your Power

Interactive UX course prototype (1440×1024, scales to any screen).

## Structure
```
index.html      main page (HTML + CSS + JS)
images/         all scene images, referenced with relative paths
```

## Publish with GitHub Pages
1. Upload `index.html`, `README.md` and the `images` folder to the root of the repository.
2. Settings → Pages → Deploy from branch → `main` / `(root)`.
3. The site opens at `https://<user>.github.io/<repo>/`.
